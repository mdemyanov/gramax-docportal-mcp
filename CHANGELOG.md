# Changelog

Все значимые изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [SemVer](https://semver.org/lang/ru/).

## [0.3.4] — 2026-09-08

Релиз только ради описания пакета: на PyPI показывается README, и предупреждение
о ловушке `articlesLanguage` из 0.3.3 туда не попало. Код, тесты и поведение
инструментов не изменились.

### Изменено

- README: в таблицу переменных окружения добавлены `GRAMAX_AI_TIMEOUT`,
  `GRAMAX_AI_ARTICLES_LANGUAGE`, `GRAMAX_AI_RESPONSE_LANGUAGE` — раньше не была
  описана ни одна из них.
- README: врезка о том, что непустой `articlesLanguage` на некоторых порталах
  обнуляет выдачу (AI-поиск не отдаёт источников, полнотекстовый возвращает ноль),
  и что с 0.3.3 значения по умолчанию у переменной нет. Та же оговорка добавлена
  к параметру `language` в таблице расширенного поиска — он уходит на портал тем
  же ключом.

## [0.3.3] — 2026-09-08

### Исправлено

- **`gramax_ai_search` не находил ничего на knowledge.nau.im**: инструмент
  подставлял `articlesLanguage=ru` из настройки по умолчанию, а на этом портале
  любое непустое значение параметра обнуляет выдачу — AI-канал отвечал «не нашёл
  информации в предоставленной базе знаний» и не отдавал ни одного источника.
  Замер 2026-09-08 (по 3 повтора на комбинацию, канал генеративный): без языковых
  параметров — 6/6 ответов с маркерами источников, с `articlesLanguage=ru` — 0/6,
  с одним `responseLanguage=ru` — 6/6. Тот же параметр обнулял и полнотекстовый
  поиск: `эскалация` — 19 результатов против 0, `уведомлени` — 50 против 0.
  Дефолт снят: `GRAMAX_AI_ARTICLES_LANGUAGE` больше не имеет значения по
  умолчанию, и без явного запроса параметр в запрос не уходит вовсе.
  `responseLanguage` не затронут — он безвреден и по-прежнему подставляется.
  Возможность задать язык статей сохранена (аргумент инструмента или переменная
  окружения): на других порталах параметр может работать.

## [0.3.2] — 2026-06-10

### Исправлено

- serverInfo в MCP initialize теперь отдаёт версию пакета, а не версию FastMCP.
- Запуск без `GRAMAX_BASE_URL` завершается понятным русским сообщением (exit 1)

## [0.3.1] — 2026-06-10

Bugfix-релиз по итогам live smoke-теста против реального портала
(план: `docs/superpowers/plans/2026-06-10-live-smoke-bugfixes.md`).

### Исправлено

- **`gramax_search` был полностью неработоспособен на реальном API** (#3):
  `breadcrumbs[].title` приходит списком фрагментов `{type, text}`, а не строкой
  (падал `TypeError`); у `properties` ключ `id`, а не `name` (падал `KeyError`).
  Добавлена контрактная фикстура по реальному ответу портала.
- **5xx и сетевые ошибки утекали англоязычным traceback** (#5): добавлены
  `GramaxServerError` и `GramaxNetworkError`, все HTTP/сетевые/JSON-ошибки
  клиента теперь возвращаются русскими сообщениями (конвенция проекта).
- **Пустой `GRAMAX_API_TOKEN` ронял httpx** (`Illegal header value`) (#4):
  токен стал опциональным — без него сервер работает в анонимном режиме
  для публичных порталов (ADR-0002). Обратносовместимо: с валидным токеном
  поведение не меняется.

### Известные ограничения

- `GET /api/user/token` требует браузерную сессию — автообновления токена нет;
  просроченный токен даёт 401 даже на публичных эндпоинтах (уберите его из
  `.env`, чтобы работать анонимно).
