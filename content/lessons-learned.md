# Lessons Learned

Append-only журнал уроков команды. Пишется по итогам задачи и только тогда, когда урок
переживает эпик; находки об инструментах и API живут в auto-memory, не здесь.

**Компакция.** Когда файл превышает 32 000 символов (порог T) — записи старше трёх
последних эпиков переезжают дословно (без переформулировки) в `content/lessons-archive/<тема>.md`
(один файл на повторяющуюся тему). Указатель на месте перенесённой записи не остаётся —
обнаружимость держит витрина `content/lessons-archive/_index.md`, которая уже служит оглавлением
архива (`ADR-065` Д1). Из процедуры остаётся три элемента: шапка, живая таблица и ссылка на
витрину архива.

**Порог старше окна.** Если записей старше трёх последних эпиков нет, а T всё равно превышен —
переносятся старейшие живые записи независимо от эпика, пока объём не станет ≤ 26 000 символов
(`ADR-065` Д2; число перемеряется формулой `T − 7 × <средняя запись на эпик>` при смене темпа).
Прямая запись урока в архив в обход живой таблицы запрещена (`ADR-065` Д3).

**Чем считать символы.** Единицу задаёт текст команды, а не переменная окружения: посимвольные
счётчики шелла, которому не задана `LC_*` — а именно такой достаётся субагенту, хуку и вам, —
молча считают БАЙТЫ и на кириллице завышают объём примерно в 1,6 раза (код возврата 0, без
единой строки предупреждения). Прибор порога объявляет свою кодировку сам; `$F` здесь — путь
к журналу:

```bash
python3 -c 'import sys,pathlib;print(len(pathlib.Path(sys.argv[1]).read_text(encoding="utf-8")))' "$F"
```

Префикс локали (`LC_ALL=…`) лечением не является: на машине, где такой локали не сгенерировано,
счёт молча возвращается к байтам — тем же способом и без диагностики.

Порог 32 000 символов **измерен на корпусе `nauta`** (p90 популяции append-only-регистров
`content/`, процедура — ADR-057-spec §1), а не назначен и не выведен эвристикой. **Для вашего
корпуса он не обязателен: перемерьте той же процедурой на своём — в тех же символах и той же
командой выше.**

**Отказ переноса и второй повод круга (`ADR-088`).** Строка без разрешённой судьбы (`destiny:
closed` в записи реестра `.nauta-lesson-destiny.yaml`) не переносится в архив ни при каком
возрасте эпика — легальность переноса держит реестр, а не давность записи. Круг компакции
запускается по любому из двух поводов: **(а) объём** — порог T выше превышен, без изменений;
**(б) разобранность** — проход триажа завершён, и в реестре есть хотя бы одна закрытая запись
без проставленного `archived-in`; партия повода (б) не зависит от размера журнала. Если T
превышен, а ни одной закрытой записи нет — перенос запрещён, процедура отказывает поимённо,
называя строки без разрешённой судьбы (`ADR-088` Д3/Д4). У свежего потомка реестра нет — его
отсутствие проходит тихо, пока триаж не начат.
