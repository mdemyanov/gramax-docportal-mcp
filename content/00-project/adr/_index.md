Architectural Decision Records проекта `gramax-docportal-mcp`. Один файл — одно значимое
решение. Номер выдаётся монотонно (`bash scripts/next-id.sh adr`), реестр —
`.nauta-ids.yaml`, пространство `adr` (`ADR-`, ширина 3).

## Решения

- [ADR-001: Streaming AI-инструмент — аккумулировать ответ + heartbeat](ADR-001-streaming-ai-tool.md) — `gramax_ai_search`
  аккумулирует весь NDJSON-стрим до закрытия соединения, парсит цитаты одним проходом и
  шлёт `ctx.report_progress` как heartbeat; таймаут 120 с через `GRAMAX_AI_TIMEOUT`.
- [ADR-002: Опциональный API-токен — анонимный режим для публичных порталов](ADR-002-optional-api-token.md) — `GRAMAX_API_TOKEN`
  необязателен: пустая строка нормализуется к `None`, заголовок `Authorization` не
  отправляется, публичные порталы работают анонимно «из коробки».

## Шаблон

- [ADR-NNN: [Название решения]](_template.md) — эталон структуры ADR (Context / Decision / Consequences /
  Alternatives / Related). Это **не** ADR и номера не занимает: имя вне glob'а
  `ADR-*.md`, поэтому гейт идентификаторов не считает его выданным номером.

## Отменённые номера

Кладбище пространства `adr` (`.nauta-ids.yaml`, ключ `graveyard`). Номер, снятый после
выдачи, записывается сюда и **не переиспользуется** — иначе ссылка на него в истории
начнёт указывать на другое решение.

Отменённых номеров нет.

## Правила

- Принятые ADR не редактируются: при смене решения — новый ADR со `Status: Superseded by
  ADR-NNN` в нём, старый файл не трогается.
- Спека-спутник решения живёт в [40-architecture/](../../40-architecture/_index.md);
  ADR отвечает «почему так», спека — «как устроено».
